## Submission handling

- The main manuscript should cite evidence identifiers, not local absolute paths.
- The complete evidence package should be archived separately or uploaded as
  supplementary material when the target venue permits it.
- Vivado project folders, generated caches and machine-specific `.runs`
  directories are not part of the manuscript package unless explicitly
  requested by the venue.
- The package should include source RTL, testbenches, input programs, scripts,
  result tables and the figure-generation script.
