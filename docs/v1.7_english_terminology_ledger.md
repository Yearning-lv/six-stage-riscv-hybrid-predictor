# v1.7 English Terminology Ledger

Use the following forms consistently in the English manuscript.

| Concept | Preferred form | Usage note |
|---|---|---|
| FPGA soft processor | `soft core` | Use `soft-core` only when it directly modifies a noun, such as `soft-core processor`. |
| Pipeline stages | `IF, ID, EX, MEM1, MEM2 and WB` | Keep stage names in uppercase. |
| Branch prediction | `branch prediction` | Use `branch-prediction front end` only as a compound modifier. |
| Branch target buffer | `branch target buffer (BTB)` | Define once, then use `BTB`. |
| Pattern history table | `pattern history table (PHT)` | Define once, then use `PHT`. |
| Global history register | `global history register (GHR)` | Use `GHR` for the state register and `Gshare` for the predictor. |
| Return address stack | `return address stack (RAS)` | Define once, then use `RAS`. |
| Data forwarding | `operand forwarding` or `data forwarding` | Use `operand forwarding` when describing source-operand selection. |
| Load-use hazard | `load-use hazard` | Keep the hyphen. |
| Pipeline flush | `pipeline flush` or `flush` | Use `flush` for the recorded event counter. |
| Misprediction | `misprediction` | Use `mispredict` only for RTL signal or counter names. |
| Register write-back | `write-back` | Keep the hyphen in prose. |
| Flip-flop resource | `flip-flops` | Use `FF` or `FFs` only in tables and resource summaries. |
| Block RAM resource | `Block RAM Tile` | Keep capitalization for the Vivado resource name. |
| Timing metric | `worst negative slack (WNS)` | Define once; use `WNS` in tables. |
| Power | `estimated on-chip power` | Do not call it measured power. |
| Clock result | `validated 50 MHz clock constraint` | Do not call it the exact maximum frequency. |
| Board result | `board-level smoke test` | Do not call LED observation a complete application demonstration. |

## Audit status

The manuscript uses intentional context-dependent variants where needed:
`soft-core processor` as a compound adjective, `soft core` as a noun,
`branch-prediction front end` as a compound modifier, and `mispredict` for RTL
signal or counter names. These variants do not represent inconsistent technical
definitions.
